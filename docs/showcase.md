## Browse and organize

Start in **My Files**. Open a folder, switch between **List** and **Grid**, and
choose **Name**, **Date Added** or **File Size** to sort. Open **Select** for
multi-item move or Trash actions. An item's menu also offers rename, star,
sharing, downloading and preloading. [Browse and organize →](usage.md#browse-and-organize)

## Upload and follow transfers

Open the destination, then use **New → Upload files** or **Upload folder**.
Review the folder summary before starting. Follow **Transfers** and keep the
browser open until **You can close this tab** appears. Keep originals until
**Completed**. [Upload instructions and status meanings →](usage.md#upload-files-or-folders)

![Expanded device upload with progress, speed, time remaining and Keep this tab open](assets/upload-progress.png)

![Completed uploads in the transfer panel](assets/upload-completed.png)

<details>
<summary>Folder upload entry point, URL imports and transfer history</summary>

![New menu with the Upload folder action](assets/upload-folder.png)

The capture shows where to start a folder upload. Follow the
[written folder-upload steps](usage.md#upload-files-or-folders) for the picker and
confirmation; the recordings demonstrate a single-file upload.

Nested folders stay together in an expandable upload task. Ordinary files and
URL imports have separate tasks. **New → Upload from URL** receives a public
HTTP(S) file on the server; source checks and subsequent stages appear in Transfers.
Accepted URL work can continue with the browser closed while TGDrive runs.

![Upload from URL controls](assets/url-import.png)

Finished history has **All / Successful / Failed / Cancelled** filters, search
and pages. Use **Show in folder** to locate a completed upload. For interrupted
device uploads, reselect the originals in the existing task to resume from the
confirmed offset. [History →](usage.md#transfer-history) ·
[Retries and resuming →](usage.md#can-i-close-the-tab)

![Finished transfer history and filters](assets/transfer-history.png)

## Read and preview

Double-click a file with a mouse or tap it on touch. **Download Original** keeps
the original available; **Escape** or browser **Back** closes the preview.
Preview support depends on the file and browser. [All preview formats and controls →](usage.md#open-preview-and-download)

![Video open in TGDrive's custom player](assets/media-preview.png)

The player includes seeking, volume and settings. Available audio tracks,
subtitles, chapters and quality choices depend on the source. Use fullscreen
where your browser supports it; touch controls include double-tap seeking.

## Share selected content

Choose **Share Link** from a file or folder's menu. Add an optional label, select
an expiry and create the link. Anyone holding it can read the shared content;
folder links include accessible descendants. [Create, edit and revoke links →](usage.md#share-and-revoke)

![Sharing dialog with a label and expiry choices](assets/share-link.png)

<details>
<summary>Recipient folder and Shared Links inventory</summary>

![A shared folder as a recipient sees it](assets/shared-folder.png)

Open **Shared Links** to find each labelled link, change its expiry, copy an
active link or revoke it. Independent links can have different purposes and
expiries. Moving or renaming an item preserves explicit links.

![Shared Links inventory with labels and expiry information](assets/shared-links.png)

**Copy Download Link** creates or reuses a separate download capability for
download managers. Keep it private and revoke it from Shared Links when finished.
Revocation cannot recall copies already downloaded.

</details>

## Restore from Trash

Use an item's **Move to Trash** action, then open **Trash**. **Deleted from**
shows its previous folder; choose **Restore** to return it. Permanent deletion
requires confirmation, removes the catalog records and cannot be undone from
Trash. Telegram originals remain in the storage channel.
[Trash and deletion behavior →](usage.md#trash-and-permanent-deletion)

![Trash showing a disposable item and its original folder](assets/trash-restore.png)

## Preload and monitor

For a movie, large download or busy share, choose **Preload file** from its menu.
Open **Monitor → Preloads** to follow the queue and inspect server cache coverage.
Preloading can continue with the browser closed while the server runs. Cache is
disposable and is not a backup. [Preload instructions →](usage.md#preload-a-file-for-smoother-playback-and-downloads)

![Preloads showing cache capacity and file coverage](assets/preloads.png)

<details>
<summary>Performance overview and server resources</summary>

Open **Monitor → Performance**. **Overview** shows network traffic and live
transfers; **Accounts** shows Telegram activity and capacity; **Resources** shows
CPU, RAM, storage and cache. Select a time range for recorded measurements.
[How to interpret the readings →](performance.md#read-the-performance-page)

![Performance Overview with traffic measurements](assets/performance-overview.png)

![Performance Resources with CPU, memory and cache readings](assets/performance-resources.png)

Values reflect this capture session and its deployment. They do not establish
speed or memory requirements for other devices or servers.

</details>

## Configure your drive

Open **Configuration** to inspect cache budgets, preloading, upload limits and
timezone. Use defaults first, change one category, and save that category to
apply it. The public visitor demo keeps these settings read-only.
[Settings, defaults and bounds →](configuration.md)

<details>
<summary>Cache, transfer and regional settings</summary>

![Cache settings for memory, disk and preloading](assets/cache-settings.png)

**Regenerate all thumbnails** rebuilds existing covers in the background after
confirmation. It can consume bandwidth; the screenshots show its entry point,
not a completed rebuild. [Thumbnail generation →](thumbnails.md)

![Thumbnail rebuild entry point](assets/thumbnail-rebuild.png)

**Transfer limits** includes uploads per bot, split size, temporary upload storage,
URL download concurrency and Telegram request budgets. Large files are split
automatically and still appear as one file. The screenshots do not demonstrate
a multi-gigabyte transfer or prove its recovery behavior.

![Upload, storage and Telegram transfer settings](assets/transfer-settings.png)

![Regional timezone settings](assets/regional-settings.png)

Appearance supports **Light**, **Dark** and **System** through its menu. Timezone
affects displayed times; stored timestamps remain UTC.

</details>

## Connections and backups

**Management → Connections** lists configured Telegram storage clients and
connection controls. Adding a bot, signing in a Premium account or replacing
credentials requires your own Telegram setup. These captures show website entry
points; they do not demonstrate a new Telegram authentication.
[Connections and credential changes →](usage.md#settings-and-connections)

<details>
<summary>Connections and Storage & Backups screens</summary>

![Connections management entry points without private credentials](assets/connections.png)

**Storage & Backups** distinguishes the saved catalog from temporary upload space.
Database backups protect the catalog; optional independent channel protection
copies completed documents too. A displayed screen is not proof of successful
backup or recovery. Follow the guide, confirm restore points and keep matching
keys outside the server. [Backup and recovery →](backup-recovery.md)

![Storage & Backups status and management entry points](assets/storage-backups.png)

</details>

## Workflows beyond these recordings

| Feature | How to use it |
| --- | --- |
| Optional Telegram bot uploads | Configure the bot and administrator IDs, choose a destination in **Transfer limits → Bot uploads**, then send files privately to the bot. [Bot instructions](usage.md#optional-telegram-bot-interface) |
| Multiple devices | Log in using the same owner password. Sessions are independent; logging out closes only that session. [Device access](usage.md#use-several-devices) |
| Protected public samples | Browse **Demo Files**; create disposable uploads in **My Files**. Configuration and Management changes remain locked for visitors. [Demo guide](usage.md#try-the-public-demo) |
| Background processing | Once server receipt is accepted, uploads can finish without the tab. URL imports and manual preloads also continue while TGDrive runs. [When to close the tab](usage.md#can-i-close-the-tab) |
| Independent channel recovery | Prepare separate recovery access, wait for a confirmed restore point, then inspect and verify before activation. [Recovery procedures](backup-recovery.md) |
| Install, upgrade or move hosts | Preserve MongoDB, Telegram access, secrets and persistent data. [Setup](setup.md) · [Operations](operations.md) |

No bot messages, Premium sign-in, destructive recovery, full-drive cache clearing
or full-library thumbnail rebuild are performed for these demonstrations.
For capture provenance and replacement instructions, see the [media guide](assets/README.md).
