New to TGDrive? [Learn the essentials](new-user-guide.md) or
[try the demo](usage.md#try-the-public-demo).

These guides cover TGDrive 2.3 with MongoDB. Use the guides and Compose files
bundled with your selected release; do not mix older source with 2.3 instructions.
Stable `main` follows published releases; `dev` may be unstable.

For your own installation:

1. **Install:** choose local, Coolify or server Compose in [Setup](setup.md).
2. **Verify:** sign in, test upload/download and confirm persistence and a backup
   using [first-login checks](setup.md#5-open-your-drive).
3. **Use:** [upload, browse, preview and share](usage.md).
4. **Protect:** save the [off-host recovery material](backup-recovery.md#save-off-host-recovery-material)
   and follow [backup and recovery](backup-recovery.md).
